# Исправление административного CRUD фильмов

Исправлены `views/movie/index.php`, `view.php`, `create.php`, `update.php` и `web/assets/css/style.css`.

- Удаление теперь использует реальную HTML-форму POST с CSRF Yii2. Старые GET-ссылки на удаление убраны как из таблицы, так и из страницы фильма.
- Фильтры перенесены в отдельную GET-форму; сортировка заголовков и пагинация Yii2 сохранены.
- Таблица выглядит как тёмная панель, на мобильном экране строки становятся отдельными карточками.
- Стиль основной пользовательской части не переписывался; новое оформление ограничено `.movie-admin`.
- Восстановлен `web/assets/css/style.css`, отсутствовавший в предыдущем ZIP. Сам файл взят из более ранней рабочей версии дизайна «Киновечера».

## Проверка в Open Server

1. Открой `index.php?r=movie/index` под аккаунтом администратора.
2. Открой инструмент разработчика и проверь, что CSS подключился без ошибки 404.
3. Нажми «Удалить» у тестовой записи, подтверди диалог. Должен отправляться POST, а не открываться ссылка `?r=movie/delete&id=...` методом GET.
4. Проверь «Изменить» и «Добавить фильм».
5. Проверь ширину окна 390 px, 900 px и 1280 px.

Не отключай CSRF в `config/web.php` и не убирай ограничение `VerbFilter` для POST.
