# Киновечер — интеграция в Yii2

Эта сборка подготовлена из вашего `basic(4).zip` и относится **только к этапу интеграции макета**.

## Что сделано
- `views/layouts/main.php` — общий layout, шапка, подвал и навигация Yii2; присутствуют `beginPage/head/beginBody/endBody/endPage`.
- `views/site/*.php` — шесть страниц со своим `$this->title` и общим `<main class="wrap">` в layout.
- `views/site/_movieCard.php` — partial карточки фильма.
- `assets/AppAsset.php` — подключение **одного** `style.css` и **одного** `app.js`, без Bootstrap.
- `web/assets/images/` — локальные JPEG; изображения в представлениях подключаются через `Html::img('@web/...')`, включая partial карточки.
- Поиск использует Yii2 `request->scriptUrl` и скрытый маршрут `r=site/catalog`: это необходимо для GET-формы при `enablePrettyUrl = false` (иначе браузер потеряет параметр `r`).
- Из `app.js` удалена неиспользуемая реализация браузерных аккаунтов; серверная авторизация PHP не изменялась. Клиентские списки фильмов остаются в localStorage.

## Запуск
1. Разархивируйте проект в папку локальных доменов OSPanel/Open Server.
2. DocumentRoot должен указывать на `basic/web` (это корень сайта Yii2).
3. Убедитесь, что установлены зависимости из `vendor/` (они входят в архив; если их нет — `composer install`).
4. Выберите подходящую версию PHP, запустите сервер и откройте домен проекта.
5. Вход/регистрация работают через серверный Yii2; аккаунты пока хранятся в `runtime/kinovecher-users.json`.

## Важно о данных и безопасности
- Архив **намеренно не содержит** `runtime/kinovecher-users.json`, логи, кэш и отладочные данные исходного проекта. Чтобы сохранить прежние аккаунты, НЕ перезаписывайте существующий JSON-файл на своём компьютере. Перед переносом резервную копию можно сделать вручную. Не публикуйте файл с аккаунтами в GitHub.
- `config/cookie-key.php` — индивидуальный ключ подписи cookie. Он включён для запуска локальной копии, но исключён из Git. Не публикуйте его. При замене ключа существующие сеансы будут сброшены.
- Аккаунты пока **не** хранятся в SQL; схема БД, миграции и CRUD — отдельный следующий этап.
- Из-за отсутствия полноценного PHP-сервера в среде сборки браузерный запуск здесь не выполнялся.
