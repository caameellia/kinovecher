# «Киновечер»: интеграция в Yii2

Это полный проект на основе присланного `basic(2).zip`. Сохраняет существующие изображения, PHP-авторизацию, формы, CSS и единый `web/assets/js/app.js`.

## Исправления

- `assets/AppAsset.php` уже содержал правильные пути к ресурсам и зависимость только от `yii\web\YiiAsset`; оставлен без изменений.
- `views/layouts/main.php`: включена регистрация `AppAsset::register($this)`; убраны ручные подключения `style.css` и `app.js` во избежание дублирования. Сохранены `$this->head()` / `$this->endBody()`, меню, поиск, данные JS.
- `views/site/_movieCard.php`: единый partial карточки фильма. На главной, в каталоге и на странице фильма карточки вызываются через `$this->render()`; сохранены данные для фильтрации и кнопки отметок в каталоге.
- Добавлены `$this->title` в представления, где он отсутствовал.
- Исправлены старые `movie.html`, `catalog.html`, `login.html` ссылки на странице фильма, локальные пути JPG и ссылка на фильм из профиля.

## Установка

1. Сделайте резервную копию текущего `basic` целиком, включая `runtime`.
2. Распакуйте ZIP в папку Open Server `domains` (не вложите одну папку `basic` в другую).
3. Откройте `http://basic/web/index.php` (если сервер направлен на корень проекта).
4. Обновите браузер с очисткой кэша (`Ctrl+F5`).
5. Проверьте через DevTools → Network, что `style.css` и `app.js` загружаются по одному разу, а изображения возвращают HTTP 200.

Для этой версии не нужны миграции или база MySQL. Аккаунты по-прежнему используют существующее файловое хранилище.

## Проверки

Проверена PHP-синтаксическая корректность изменённых файлов, синтаксис JS, наличие JPG и целостность ZIP. Полная проверка в Windows/Open Server из этой среды недоступна.
